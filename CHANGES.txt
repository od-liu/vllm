AsyncLLM迁移 - 文件变更清单
===============================

修改日期: 2025-12-02
修改原因: 解决请求58卡死问题 - 迁移到AsyncLLM
修改类型: 架构级重构（从同步+线程池改为完全异步）

==================================================
修改的源代码文件 (2个)
==================================================

1. vllm/profiler/trace_scheduler.py
   变更类型: 重大修改
   主要变更:
   - 导入: 移除 ThreadPoolExecutor, threading; 添加 AsyncLLM
   - __init__: 移除 ThreadPoolExecutor 初始化
   - _schedule_single_request: 
     * 移除 run_in_executor 调用
     * 移除 heartbeat 监控线程
     * 使用 AsyncLLM.generate() 异步生成器
   - schedule_requests: 移除 executor.shutdown() 调用
   
   影响范围: 所有使用 TraceScheduler 的代码
   向后兼容: 否（需要传入 AsyncLLM 而不是 LLM）

2. benchmarks/benchmark_e2e_metrics.py
   变更类型: 重大修改
   主要变更:
   - 导入: 移除 LLM; 添加 AsyncLLM, AsyncEngineArgs
   - run_e2e_benchmark_single_rank:
     * 使用 AsyncEngineArgs 初始化
     * 使用 AsyncLLM.from_engine_args()
     * warmup 改为异步循环
     * 添加 llm.shutdown() 清理
   - vocab_size 访问: llm.llm_engine.model_config → llm.model_config
   
   影响范围: 所有调用此函数的benchmark脚本
   向后兼容: 否（行为变化，但接口不变）

关键代码变更详情
==================================================

### TraceScheduler.__init__

之前:
  def __init__(self, llm: LLM, mapper, sampling_params, max_concurrent=5):
      self.executor = ThreadPoolExecutor(
          max_workers=max_concurrent * 2,
          thread_name_prefix="trace_scheduler"
      )

现在:
  def __init__(self, llm: AsyncLLM, mapper, sampling_params, max_concurrent=5):
      # 无ThreadPoolExecutor

### TraceScheduler._schedule_single_request

之前:
  result = await asyncio.wait_for(
      loop.run_in_executor(
          self.executor,
          lambda: self.llm.generate([prompt_dict], sampling_params)
      ),
      timeout=timeout
  )

现在:
  async def generate_with_timeout():
      nonlocal result
      async for output in self.llm.generate(
          request_id=request_id,
          prompt=prompt_dict,
          sampling_params=sampling_params,
      ):
          result = output
          if output.finished:
              break
      return result
  
  result = await asyncio.wait_for(
      generate_with_timeout(),
      timeout=timeout
  )

### Benchmark LLM初始化

之前:
  llm = LLM(
      model=config.model_path,
      tensor_parallel_size=config.tensor_parallel_size,
      ...
  )

现在:
  engine_args = AsyncEngineArgs(
      model=config.model_path,
      tensor_parallel_size=config.tensor_parallel_size,
      ...
  )
  llm = AsyncLLM.from_engine_args(engine_args)
